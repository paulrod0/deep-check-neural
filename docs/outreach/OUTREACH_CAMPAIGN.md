## How to send

1. Open each `.html` file in `outreach/emails/` in Chrome
2. **Cmd+A** to select all, **Cmd+C** to copy
3. In Gmail: Compose > paste with **Cmd+V**
4. The **To** and **Subject** are shown at the top of each email
5. Review, adjust if needed, and send

Or use the Gmail draft batch below (copy-paste into Gmail drafts).
