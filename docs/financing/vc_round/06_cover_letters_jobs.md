## ⚠️ PROTECCIÓN IP de Deep-Check

**Antes de firmar cualquier contrato, verifica:**

1. **Cláusula IP:** el contrato NO puede reclamar propiedad de:
   - Código escrito fuera del horario laboral
   - Proyectos previos (Deep-Check ya existe)
   - Invenciones en mi campo independiente

2. **No-compete / Exclusividad:** verificar alcance. Si dice "cualquier proyecto en el mismo sector" = peligro para Deep-Check. Si dice "solo durante jornada laboral" = OK.

3. **Obligación de notificación:** algunos contratos piden avisar de proyectos paralelos. Declara Deep-Check y Vanguard Peak por escrito al firmar.

4. **Dedicación:** si es jornada completa presencial, tu runway para Deep-Check se reduce. Contract/freelance es más seguro.

**Recomendación:** prioriza **contract B2B UK** (Oliver Bernard) sobre nómina española. Ganas más, mejor IP protection, y mantienes optionality para Deep-Check.
