# Assets visuales · Artículo revista de defensa

Set completo de imágenes para acompañar el documento `09_uso_defensa_seguridad_infra_criticas.pdf`. Brand consistente con los pitch decks de Deep-Check (navy `#0a2540` + accent `#00d2ff`).

## Formatos disponibles

Cada asset está en **dos formatos**:

- **`*.svg`** — vectorial, escalable a cualquier tamaño sin perder calidad. Formato preferido para revistas digitales y maquetación moderna (InDesign, Affinity Publisher).
- **`png/*.png`** — rasterizado a **300 DPI** (calidad de imprenta). Para revistas impresas o cuando la maquetación pide PNG.

## Recomendaciones de maquetación

- **Color principal**: navy `#0a2540` (Pantone 539 C aproximado)
- **Color secundario**: cyan `#00d2ff` (Pantone 305 C aproximado)
- **Tipografía**: Helvetica/Arial sans-serif. Si la revista tiene tipografía propia, los SVG son editables — pueden convertir el texto a su fuente corporativa abriendo el archivo en Illustrator/Inkscape.
- Los SVG **no contienen tipografías embebidas** — usan `font-family="Helvetica, Arial, sans-serif"` para que el sistema sustituya por la familia disponible.

## Si la revista necesita ajustes

Como los archivos son SVG editables:

- Cambiar logos por la versión final con identidad gráfica consolidada
- Adaptar paleta a la línea editorial (cualquier hex en el archivo se cambia con buscar/reemplazar)
- Traducir textos a otros idiomas
- Reducir información (el artículo puede pedir versiones más sintéticas)
- Aumentar tamaño físico sin pérdida de calidad
